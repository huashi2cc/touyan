# 基线状态模板

> **使用**：每条基线的"常态"记忆一张，文件名 `基线_<名>.md`（如 `基线_AI.md`），存于 `基本面报告和建议策略/基线状态/`。
> **作用**：这是从卖方报告吸收出来的基线认知，是**每日提示卡排序的依据**（基线状态越有利，标的越靠前）。

---

# 基线状态 · <基线名>

- **周期定位**（天时·产业结构性增长）：景气上行/下行 · 初/中/末段
- **估值定位**（地利·估值分型）：贵 / 合理 / 便宜（相对盈利增速）
- **情绪定位**（人和·四区间）：区间1贴水 / 区间2平水 / 区间3升水 / 区间4降水
- **关键驱动**（寻根源）：第一性原理增长根源
- **主要矛盾**（定矛盾）：当前供需矛盾点
- **久期推演**（推久期）：理由能支撑的时长
- **证伪信号**：什么数据/信号出现即基线不成立（对应反转看）
- **跟踪频率**：基线更新节奏
