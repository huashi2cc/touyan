# 投研工具介绍

> 面向非专业读者。读完这一页，你就知道这个工具是什么、怎么用、原理是什么。

---

## 一句话说明

**它不帮你炒股，它帮你每天做一张"今天该关注哪些股票、先看谁"的便签卡，并在你交易时防止你冲动跑偏。**

---

## 你每天实际拿到什么

一张卡片，长这样：

```
【提示卡 · 9月17日】
主线：人工智能（覆盖芯片、软件、甚至AI制药）

① 芯片设备A —— 工厂在扩产，理由能撑6-12个月 · 若大厂砍订单就作废
② 代工厂B —— 产能利用率回升，能撑6个月 · 若利用率掉头就作废
③ 软件C —— 用户放量初期，能撑1年 · 若订阅增速放缓就作废
```

就这些。**①排在最前 = 优先关注**。

它不告诉你几点几块钱买、跌到哪止损、买多少——那些是你自己的操作习惯，它只负责四件事：

- **看谁**（标的清单）
- **为什么**（一句话理由）
- **看多久**（这个理由能撑多长时间）
- **什么时候理由作废**（出现什么信号就该重新审视）

历史卡全部按日期留档。过段时间回头翻：当时排第一的后来涨了吗？排错的错在哪？**用它复盘，会越用越准。**

## 背后的原理：三步

### 第一步：借别人的脑子

证券公司有几百个专业分析师天天调研写报告（卖方报告）。普通人没能力、也没时间搞懂所有行业，所以这个系统的思路是——**不自己预测世界，站在巨人肩膀上消化他们的结论**。

### 第二步：把报告浓缩成"基线"

读完报告后，它不记结论，记**"这件事现在处于什么常态"**，三个维度：

| 维度 | 问的问题 | 通俗理解 |
|------|----------|----------|
| 景气 | 这个行业在上升期还是衰退期？ | 现在是春天还是冬天 |
| 估值 | 现在买是贵还是便宜？ | 相对它的赚钱能力值不值这个价 |
| 情绪 | 大众对它冷淡还是狂热？ | 菜市场没人排队还是挤破头 |

### 第三步：每天导出一张卡

把基线里状态最好的几个标的排个序，就是当天的卡。**每天一张，顺序即优先级。**

---

## 两个核心判断工具（原理的心脏）

### ① 情绪的四个季节（四区间）

任何一轮行情，大众情绪都像四季轮转：

| 编号 | 名字 | 大众状态 | 该怎么办 |
|------|------|----------|----------|
| 区间1 | 贴水 | 恐慌，没人想买 | 只买被硬数据验证过的，仓位卡死 |
| 区间2 | 平水 | 恢复冷静 | 最舒服的区间，按部就班 |
| 区间3 | 升水 | 狂热，什么故事都信 | 可以追热度，但知道自己在玩情绪 |
| 区间4 | 降水 | 退烧 | 撤退，回到只看硬数据 |

### ② 挑票的四个格子（四象限）

每只股票问两个问题：它的上涨是**真业绩**还是**讲故事**（竖轴）？大资金**认不认**（横轴）？

```
              真业绩驱动
                 │
     2象限        │       1象限
   真业绩·没人认   │   真业绩·资金认
   （靠后，得等）  │  （第一优先）
 ────────────────┼────────────── 
     3象限        │       4象限
   讲故事·没人认   │   讲故事·资金认
  （平时别碰）     │   （第二，故事有1撑腰）
                 │
              故事题材驱动
```

- **1象限**（真业绩+资金认）→ 第一优先
- **4象限**（讲故事+资金认）→ 第二，短期也硬
- **2象限**（真业绩+没人认）→ 靠后，等风来
- **3象限**（讲故事+没人认）→ 平时回避；但狂热季（区间3）它弹得最凶

## 保险带

系统里有一份"宪法"（策略导出RULES），是凌驾于一切之上的安全规则。例如：

- **市场恐慌期（区间1）仓位一律锁死，不许加**
- 不许押上全部身家
- 每笔交易必须有记录，无记录不交易
- 亏了不许报复性交易

**它最大的作用是防止你在头脑发热时毁掉自己**——在市场里，活下来比赚一笔重要。

---

## 它明确不做的三件事

1. **不预测**明天涨跌——它只准备"涨了怎么办、跌了怎么办"
2. **不代客交易**——不下单、不碰钱，你始终自己动手
3. **不管执行细节**——买卖点、止损位是你自己的功夫，它只负责让你别偏离计划

---

## 总结

**专业机构的调研 + 一套情绪四季的判断法 + 一份每天一页的行动清单 + 一条勒住冲动的保险带。**

外行用它，等于随身带了一个研究团队和一个冷静的刹车。
